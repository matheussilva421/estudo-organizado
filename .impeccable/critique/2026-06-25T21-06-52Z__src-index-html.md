## Anti-Patterns Verdict

Not AI slop. Committed dark instrument identity: stratified near-black surfaces, DM Mono reserved for measurement, Plus Jakarta for prose, accent-rare steel-blue, real elevation; identity holds across themes. SaaS tells leak only on Dashboard (4 stat cards with arbitrary green/blue/orange/red stripes) and Habitos (3x3 grid of 9 identical cards with decorative colored underlines) — the "qualquer startup" / "identical card grids" patterns PRODUCT.md rejects.

Deterministic scan (detect.mjs over src): 258 findings — 234 advisory, 24 warning, zero absolute-ban errors.
- 136 color-drift: most legit (6 theme defs in themes.css; isolated lab/), but a real cluster of off-token generic hexes (#f59e0b #10b981 #ef4444 #6b7280 #3b82f6) in layout.css/styles.css/dashboard.css = the stat-card colors.
- 97 radius-drift: 10px and 2–24px outside the documented 8/14/18 scale. DESIGN.md rounded scale is not the real source of truth.
- 7 side-tab: border-left 3–4px beyond the one sanctioned event-card stripe.
- 11 layout-transition: transition: width/height on progress bars/charts/sidebar.
- False positives: 4 overused-font (Plus Jakarta is committed identity), 1 numbered-section (planejamento wizard is a real 4-step flow).

Browser/contrast evidence: WCAG audit across all 6 themes. The "AA in all six themes" claim essentially holds — primary text 13–16.5:1, secondary 7–9.7:1, --text-muted tuned to >=4.5:1 in every theme (tightest 4.56 in Neon). Only sub-AA value anywhere: danger on card in Arrakis = 4.42:1 (vs 4.5) — near-miss for small coral text.

## Overall Impression

Confident, identity-rich instrument panel that already beats the SaaS-slop bar. Biggest opportunity is internal consistency: two screens (Dashboard, Habitos) speak a louder, more generic dialect than the rest, and DESIGN.md tokens have drifted from the code.

## What's Working

1. Verified contrast across six themes — measured, not asserted; --text-muted re-tuned per theme to clear 4.5:1.
2. The measurement language — DM Mono on timer/time chips/KPI values, Plus Jakarta elsewhere; sans-mono contrast makes data pop without color.
3. Empty states that teach — Ciclo de Estudos, Inteligencia de Banca right-pane, dashboard "Sem dados".

## Priority Issues

[P1] Two divergent dashboard dialects + decorative multicolor stat cards (Home neutral vs Dashboard/Editais Anteriores/Habitos colored, off-token hexes). The "qualquer startup" tell + Consistency hit. Fix: unify on Home's neutral stat-card vocabulary; reserve color for meaning; replace generic hexes with tokens. Command: /impeccable colorize then /impeccable polish.

[P1] First-run modal intercepts the dashboard before anything is visible ("Qual e seu edital principal?" covers Home on first load). Modal-as-first-thought blocking the #1 user need. Fix: inline principal-edital selection (banner / empty-state CTA) or default to all editais. Command: /impeccable onboard.

[P2] Coral/red used for neutral "remaining/pendentes" counts (Home, mobile). Red = danger in the system's own semantics; pending isn't an error. Fix: neutral/muted for remaining; reserve coral for true errors and overdue. Command: /impeccable colorize.

[P2] Design system drifted from code (tokens not source of truth): 97 radius hits (real usage 10px; documented 8/14/18) and off-token colors. Fix: reconcile DESIGN.md scale + ramps, refactor stray hexes to tokens, re-run detector. Command: /impeccable extract or /impeccable audit.

[P2/P3] Undocumented side-stripes + animated layout properties: 7 border-left 3–4px stripes (most status/category, defensible but undocumented; subject-manager 4px accent is decorative) and 11 transition: width/height. Fix: document status/category left-marker rule (drop decorative accent stripe); switch width transitions to transform: scaleX with reduced-motion fallback. Command: /impeccable animate then /impeccable polish.
