# Cache Bump 8.98 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar os assets do app com a versão de cache `8.98`.

**Architecture:** Manter uma única versão de release alinhada entre as URLs de
assets do HTML, o cache do service worker e o diagnóstico de sync. O teste de
arquitetura protege essa igualdade sem alterar os specifiers ES `8.37`.

**Tech Stack:** HTML, JavaScript ES modules, Vitest.

---

**Files:**
- Modify: `tests/unit/css-architecture.test.js`
- Modify: `src/index.html`
- Modify: `src/sw.js`
- Modify: `src/js/sync/sync-diagnostic.js`

- [ ] **Step 1: Escrever a expectativa que falha**

No teste `keeps browser cache busting aligned with the current app version`,
exigir `8.98` no HTML, no `APP_VERSION` e no `DIAGNOSTIC_BUILD_VERSION`.

- [ ] **Step 2: Confirmar RED**

Run: `npm.cmd test -- tests/unit/css-architecture.test.js`

Expected: FAIL porque o HTML/service worker ainda usam `8.97` e o diagnóstico
usa `8.96`.

- [ ] **Step 3: Aplicar o bump mínimo**

Trocar `8.97` por `8.98` apenas nas URLs de assets em `src/index.html` e em
`APP_VERSION`; trocar `DIAGNOSTIC_BUILD_VERSION` de `8.96` para `8.98`. Manter
inalterados todos os imports `?v=8.37`.

- [ ] **Step 4: Confirmar GREEN**

Run: `npm.cmd test -- tests/unit/css-architecture.test.js`

Expected: PASS, 44 testes.

- [ ] **Step 5: Validar e publicar**

Run: `npm.cmd test -- --maxWorkers=1`

Expected: PASS, sem testes falhos. Depois, registrar o handoff, revisar o diff,
commitar somente os seis arquivos desta tarefa e fazer push de `main`.
