# Changelog - Refatoração v8.30

## Resumo

Esta versão focou em eliminar globals `window.*`, extrair módulos de views, criar módulos de estado compartilhado, limpar warnings de lint e expandir significativamente a cobertura de testes.

**Antes:** 177 referências a `window.*`, 44 warnings de lint, 420 testes unitários
**Depois:** 0 referências fora do `main.js`, 0 warnings, 528 testes unitários (+108)

## 6. Arquitetura

### 6.1 Novo Fluxo de Imports

```
Antes:
  window.EstudoApp.showConfirm(...)
  window.EstudoApp.renderCurrentView()
  window._cronoInterval = ...

Depois:
  import { showConfirm } from '../app.js'
  import { renderCurrentView } from '../components.js'
  import { setCronoInterval } from '../state/chart-state.js'
```

### 6.2 Módulos de Estado

```
src/js/state/
├── chart-state.js       # Chart.js instances
└── dashboard-context.js # Dashboard discipline/tab context
```

### 6.3 Action Dispatcher

Todas as ações `data-action` agora usam imports diretos em vez de delegação via `window.EstudoApp`:

```
src/js/ui/actions/
├── config.js       # Sync, backup, theme, notifications
├── editais.js      # Edital tree operations
├── eventos.js      # Timer CRUD, session registration
├── habitos.js      # Habit tracking
├── modais.js       # Modal open/close
├── navegacao.js    # View navigation
├── planejamento.js # Ciclo, grade, wizard
└── revisoes.js     # Revision management
└── dispatcher.js   # Central action registry
```

## 7. Breaking Changes

Nenhum breaking change para o usuário final. Todas as mudanças são internas de arquitetura.

### Para desenvolvedores:

- `window.EstudoApp` ainda funciona via namespace em `main.js` (compatibilidade)
- Legacy bridges mantidos para: `state`, `navigate`, `renderCurrentView`, `showToast`, `openModal`, `closeModal`, `saveStateToDB`, `openRegistroSessao`, wizard functions
- Handlers inline HTML (`onclick="window.EstudoApp.xxx()"`) ainda funcionam via bridges
