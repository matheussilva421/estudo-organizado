# Estado persistente do projeto

Esta pasta contém o estado técnico canônico para continuidade entre agentes.

- `CURRENT.md`: estado atual e próxima ação obrigatória.
- `PLAN.md`: plano vivo do projeto.
- `DECISIONS.md`: decisões técnicas.
- `RECOVERY.md`: snapshot mecânico para recuperação.
- `LOG.md`: milestones resumidos.
- `plans/`: planos detalhados opcionais.

Não registre credenciais, sessões, transcrições ou valores de variáveis de ambiente.
